# Smart Reading Room Management

## Run
1. Install MongoDB and make sure it is running.
2. Copy `backend/.env.example` to `backend/.env`.
3. Run `npm.cmd install`, `npm.cmd run install:all`, then `npm.cmd run dev`.
4. Open http://localhost:5173 and create an account.
5. Change an account role to `admin` in MongoDB Compass, then use **Create 100 Seats**.
